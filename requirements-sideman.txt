# The one Sideman pin. Installed AFTER requirements.txt and with --no-deps, by install.sh
# and CI:
#
#     uv pip install -r requirements.txt
#     uv pip install --no-deps -r requirements-sideman.txt
#
# --no-deps because Roadie imports only sideman.client and sideman.listen, which need numpy and
# soundfile (pinned in requirements.txt) and nothing else. Without it the install also pulls in
# `mcp`, Sideman's core dependency, and 23 packages under it (pydantic, starlette, cryptography,
# ...) whose versions float. With --no-deps the `[listen]` extra is not resolved either, so
# numpy and soundfile must stay pinned in requirements.txt: they are the ones that count.
#
# Sideman, the Ableton bridge and the measurement core. stems2live and session_view reach Live only through
# `sideman.client.Live`; roadie_analysis builds on the public names of `sideman.listen` (levels, spectra, the
# manifest readers), which is why the `listen` extra (numpy, soundfile) is asked for: it makes the resolver check
# the numpy and soundfile pinned in requirements.txt against what Sideman needs (numpy>=1.24, soundfile>=0.12).
# (Under --no-deps that check does not run: keep those pins compatible by hand.)
#
# PINNED TO A COMMIT OF SIDEMAN'S BRANCH feat/yt2live-audio-layer, not its main: the public names exist only
# there. MOVE THIS PIN TO SIDEMAN MAIN (then to a tag, or PyPI once Sideman publishes) as soon as that branch
# merges. The v0.1.0 tag is 66 commits older than the Remote Script users have installed, so it is not an option.
