# The MCP SDK, for Roadie's MCP server (roadie_mcp.py, `roadie mcp`) and nothing else. Installed
# AFTER requirements.txt and requirements-sideman.txt, by install.sh and CI:
#
#     uv pip install -r requirements.txt
#     uv pip install --no-deps -r requirements-sideman.txt
#     uv pip install -r requirements-mcp.txt
#
# Why a file of its own: Sideman is installed --no-deps so that `mcp` and the packages under it do
# not float into every Roadie venv unpinned (see requirements-sideman.txt). The server does need them,
# so here they are, every one pinned: this is `uv pip compile --universal` of `mcp==2.3.0`
# (the version Sideman's server runs; Sideman asks for mcp>=2.2,<3) against the versions in the venv
# the suite was run in, so an install gets exactly what was tested. Without this file the CLI side
# works as before; only `roadie mcp` stops, with an install hint.
#
# Four packages below (cffi, idna, pycparser, typing-extensions) are also pulled in, unpinned, by
# requirements.txt (soundfile, librosa): installed last, this file is the pin in force for them. numpy,
# scipy, soundfile, librosa and numba are not in the mcp tree and cannot move.
#
# To move to a newer mcp: put the new version in a one-line file and run
#     uv pip compile <file> --python-version 3.13 --universal --no-header --no-annotate
# then paste the result below this comment and run the suite (test_roadie_mcp.py).
